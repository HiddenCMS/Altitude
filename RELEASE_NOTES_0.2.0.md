## Nouveautes

- Ajout d'une option d'apparence permettant d'afficher ou masquer l'en-tete de chaque widget.
- Le choix de l'en-tete reste independant du style de carte (standard, bordure ou transparent).

## Compatibilite et migrations

- PHP : 8.1 ou version superieure.
- Core : HiddenCMS 0.4 a 0.7.
- Migration : aucune.
