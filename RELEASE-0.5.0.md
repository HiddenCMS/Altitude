# Altitude 0.5.0

## New features

- Add a complete tabbed theme customizer for visual identity, header, navigation, cover, layout, typography and footer.
- Add extended color controls for surfaces, borders, muted text, navigation states and footer styling.
- Add media-library cover selection with framing, sizing, repetition, attachment, height, overlay and vertical alignment controls.
- Add configurable content widths, spacing, corner radii, card shadows, font families, base size and heading weight.

## Improvements

- Apply customization through validated CSS variables while preserving existing installations with stable fallback values.
- Complete French translations for theme customization and frontend interfaces.
- Keep each customization section independently saveable and directly addressable.

## Compatibility

- PHP: >= 8.1.
- HiddenCMS Core: ^0.9.
- Database migration: none.
