## Nouveautes

- Navigation desktop et mobile revue avec sous-menus, panneau mobile et indication fiable de la page active.
- Barre de navigation fixe qui se masque à la descente et réapparaît à la remontée.
- Nouvelles options d'alignement vertical pour les lignes du Live Editor.
- Helpers cumulables pour les widgets : `no-padding`, `no-margin`, `parent-height` et `parent-width`.
- Bouton flottant avec icône pour rouvrir les préférences de cookies.

## Corrections

- Le fil d'Ariane respecte maintenant le réglage de l'outline actif.
- Le pied de page ne contient plus de copyright écrit en dur et utilise uniquement les widgets configurés.
- Les variantes d'apparence et l'affichage de l'en-tête des widgets restent indépendants.

## Compatibilite et migrations

- PHP : 8.1 ou version superieure.
- Core : HiddenCMS 0.4 à 0.7.
- Migration : aucune.
