# Altitude

Altitude est un theme front HiddenCMS destine aux associations, clubs sportifs,
sites outdoor et organisations locales. Son identite s'inspire du site du
Groupe Montagnard Roannais et de la structure en regions du theme Hydrogen de
Gantry 5, avec une implementation originale adaptee a HiddenCMS.

## Installation

```bash
composer require hiddencms/altitude
php tools/addons.php sync
```

Activez ensuite Altitude depuis **Themes & Addons**. Les couleurs, la largeur du
contenu, la hauteur et le cadrage de la couverture sont configurables depuis la
page d'apparence du theme.

## Regions

- Barre haute
- Identite
- Navigation
- Couverture
- Avant-contenu
- Contenu
- Apres-contenu
- Pied de page

La photographie de couverture par defaut a ete generee pour Altitude et peut
etre remplacee ou completee avec les outlines et widgets du CMS.
